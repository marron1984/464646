# 乃木坂46 推しメディアコレクター

ブラウザだけで完結する、乃木坂46の画像・動画自動収集ツール。
**インストール不要** - HTMLファイルを開くだけで使えます。

## 特徴

- **ローカル環境不要** - ブラウザだけで動作。Python/Node.js等のインストール不要
- **推し設定** - 推しメンバーを登録すると優先的に収集
- **推し順位** - ドラッグ&ドロップで推し順を管理
- **ブログ画像収集** - 公式ブログからメンバー別に画像を自動取得
- **YouTube動画検索** - 推しメンバー名で自動検索（YouTube Data API使用）
- **ギャラリー** - 収集した画像・動画をブラウザ内で閲覧
- **ZIP一括保存** - 収集画像をZIPにまとめてダウンロード
- **データ永続化** - 設定・収集データはlocalStorageに自動保存
- **エクスポート/インポート** - 設定・データのバックアップ＆復元

## 使い方

### 1. 開く

`index.html` をブラウザで開くだけ。

GitHub PagesにデプロイすればURLからアクセスも可能。

### 2. 推し設定

メンバー一覧からクリックで推しを追加。ドラッグで順位変更。

### 3. 収集

「収集」タブで「ブログ画像」「YouTube」「まとめて」から選んで開始。
推しメンバーが自動的に優先されます。

### 4. ギャラリー

収集結果はギャラリーに蓄積。推しのみフィルタ、画像/動画切替可能。

## 設定

### YouTube API キー

YouTube動画検索には Google YouTube Data API v3 のキーが必要です。
[Google Cloud Console](https://console.cloud.google.com/apis/credentials) で取得し、設定タブに入力してください。

### CORS プロキシ

ブログ画像の取得にCORSプロキシが必要な場合があります。
デフォルトで `https://corsproxy.io/?` が設定されています。

## ファイル構成

```
index.html          # メインページ
css/style.css       # スタイル
js/
  members.js        # メンバーデータベース
  store.js          # localStorage データストア
  scraper.js        # ブラウザベーススクレイパー
  gallery.js        # ギャラリー表示
  app.js            # メインアプリ
```
